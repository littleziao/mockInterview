# 将简历分析记录建模为独立历史资产

用户需要管理曾经成功解析过的简历，并能从这些解析结果重新进入面试准备流程。我们将简历分析记录作为独立于面试记录的历史资产保存，而不是只把简历分析嵌入已开始的面试中；这样解析成功但尚未开始面试的结果也能被复用和删除，同时历史与趋势仍只负责已完成面试记录。

## Consequences

- 每次成功解析简历都会创建新的简历分析记录，不自动覆盖或去重。
- 从简历分析记录进入面试时，系统回到简历分析确认步骤，而不是直接开始提问。
- 面试可选关联来源简历分析记录用于追溯，但删除简历分析记录不级联删除已开始或已完成的面试。
- 删除历史与趋势中的记录只删除单条已完成面试记录，并从长期趋势中移除，不影响简历分析历史。
