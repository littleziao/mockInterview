# 将岗位 JD 建模为可选校准输入

用户希望基于具体招聘 JD 练习面试，但系统的核心仍是围绕个人简历进行连续对话式模拟面试。我们将目标岗位 JD 建模为新建面试流程中的可选纯文本校准输入，用于增强简历分析、提问策略、岗位匹配度评分和复盘反馈；它不是必填项，也不把系统变成固定岗位模板或 JD 题库。

## Consequences

- 上传简历页同时承载 Markdown 简历、可选目标岗位和可选目标岗位 JD；修改任一上游输入都会让后续简历分析和面试会话显式失效。
- 简历分析会包含岗位 JD 分析，用户可在简历分析确认步骤查看和编辑系统对 JD 的结构化理解。
- 简历分析记录保存 JD 原文，面试记录保存开始面试时确认下来的 JD 快照，以保证历史复用和复盘追溯不受后续变更影响。
- 有 JD 时，面试仍以简历项目、技术基础和真实经历为主要追问载体，只提高 JD 匹配和岗位缺口的权重，不逐条拷问 JD 要求。
- 长期趋势第一版继续按目标岗位筛选和对比，不按具体 JD 聚合趋势，避免数据过度碎片化。
