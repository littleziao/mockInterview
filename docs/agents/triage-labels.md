# Triage 标签

Matt Pocock 工程技能使用五个标准 triage 角色。本文件记录这些角色在本仓库 issue tracker 中对应的真实标签名。

| 技能中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给 agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不处理 |

当技能提到某个 triage 角色时，使用本表对应的标签字符串。

如果以后 GitHub 仓库中采用了不同标签名，直接修改本文件右侧标签即可。
